# SteelProof

AI-powered startup idea validator.

Submit your startup idea in plain language and SteelProof stress-tests it from market, technical, competitive, and financial angles — delivering a scored report with red flags, green lights, and specific de-risking experiments.

**Live site:** [steelproof.ctonew.app](https://steelproof.ctonew.app)

## Tech Stack

- **Runtime:** Bun
- **Build tool:** Vite
- **Frontend:** React + TypeScript
- **Framework:** TanStack Start
- **Styling:** Tailwind CSS
- **Payments:** Stripe

## Getting Started

```bash
bun install
bun run dev
```

The dev server starts on port 3000.

## Publishing

```bash
bun run publish
```

Builds the production bundle and serves it on port 3000.
